# Ассеты с котами

Групповой ассет находится в `three-cats/video.webm`, а разметка — в `three-cats/motion-map.json`. Второй ассет с одним белым котом находится в `white-cat/`; его фон удаляется offline-моделью `u2net`, а карта делит ролик на четыре фразы.

`three-cats/video.webm` содержит полный согласованный референс в оригинальном направлении. Удалены только зелёный фон и пустые вертикальные поля. Для приложения все три кота являются одним неделимым объектом. Карта описывает пять движений, их темп, энергию, плавность, структуру, повторяемость и безопасность резкого перехода.

Требования:

- WebM VP9 с alpha channel;
- прозрачный фон;
- без аудиодорожки;
- рекомендуется 30 fps и размер до 8 МБ;
- keyframe не реже чем раз в 0,5 секунды и на каждой границе motion segment;
- лишнее пустое поле вокруг трёх котов обрезано;
- все три кота остаются одним видеообъектом.

Для первичной chroma-key обработки используйте:

```bash
tools/assets/process-cats.sh input.mp4 extension/assets/cats/three-cats/video.webm
```

У этого универсального скрипта есть необязательные аргументы: начало, длительность, цвет фона, similarity и blend.

```bash
tools/assets/process-cats.sh input.mp4 extension/assets/cats/three-cats/video.webm 1.25 4.0 0x00FF00 0.18 0.08
```

Для точного воспроизведения текущего ассета из оригинального файла 608×1080 используйте:

```bash
tools/assets/process-reference-cats.sh input.mp4 extension/assets/cats/three-cats/video.webm
```

Значения нужно подобрать по исходнику. После кодирования проверьте края шерсти, лапы и motion blur на белом, чёрном и цветном фоне. При зелёном ореоле увеличьте despill или вручную доработайте маску.

Референс исходника: <https://www.youtube.com/shorts/_VvPjfjOpxE>. Исходный ролик и обработанный результат можно публично распространять только при наличии соответствующих прав.

Референс белого кота: <https://www.youtube.com/shorts/n-fAvGiKt3c>. Его исходник и обработанный WebM также не входят в публичный репозиторий.
