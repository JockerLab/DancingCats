# Каталог танцевальных ассетов

Каждый набор котов хранится изолированно:

```text
assets/
├── catalog.json
└── cats/
    └── <asset-id>/
        ├── video.webm
        └── motion-map.json
```

Чтобы добавить нового кота:

1. Создайте папку `assets/cats/<asset-id>`.
2. Добавьте прозрачный VP9 WebM без звука.
3. Создайте `motion-map.json` по описанной ниже схеме.
4. Добавьте запись в `assets/catalog.json`.
5. Запустите `python3 tools/validate_extension.py`.

Поле каталога `videoIncluded: false` означает, что WebM намеренно не распространяется в публичном репозитории и должен быть установлен локально. Карта движений при этом остаётся версионируемой.

## Motion map

Верхний уровень:

- `id` совпадает с id каталога;
- `video` — путь к WebM относительно карты;
- `duration` — точная длительность WebM;
- `nativeBpm` — темп, при котором движение идёт с исходной скоростью;
- `phraseBeats` — полная длительность фразы в ударах;
- `transition` — способ скрыть переход последнего кадра к первому;
- `segments` — непрерывное покрытие видео движениями.

Каждый segment содержит:

- `sourceStart` и `sourceEnd`;
- `beats` — музыкальная длина движения;
- `energy` — относительная интенсивность от 0 до 1;
- `tags` — семантические признаки для будущего планировщика;
- `entryPose` и `exitPose`;
- `next` — допустимые следующие сегменты. Движок сначала предпочитает совпадение `exitPose` → `entryPose`, затем выбирает ближайшую `energy`;
- `anchors` — соответствие локального номера удара времени исходного WebM.

Якоря должны быть строго возрастающими. Первый якорь соответствует `sourceStart` и beat 0, последний — `sourceEnd` и `segment.beats`. Между ними движок использует линейный time warping, поэтому кадры идут последовательно, а не выбираются случайно.

Пример:

```json
{
  "id": "wave",
  "sourceStart": 0.0,
  "sourceEnd": 2.0,
  "beats": 4,
  "energy": 0.7,
  "entryPose": "front",
  "exitPose": "front",
  "next": ["wave", "jump"],
  "anchors": [
    { "beat": 0, "time": 0.0, "strength": 1.0 },
    { "beat": 1, "time": 0.46, "strength": 0.6 },
    { "beat": 2, "time": 1.02, "strength": 1.0 },
    { "beat": 3, "time": 1.5, "strength": 0.6 },
    { "beat": 4, "time": 2.0, "strength": 1.0 }
  ]
}
```
