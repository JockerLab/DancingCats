# Dancing Cats for YouTube

Минимальное Chromium-расширение накладывает одну неделимую группу из трёх танцующих котов поверх обычного YouTube video. Вся музыкальная разметка и хореография рассчитываются локальным backend до появления котов на экране.

YouTube Shorts, захват звука вкладки, real-time beat detector, browser fallback, crossfade, зеркалирование и масштабные импульсы не используются.

## Поток работы

```text
клик по action
    ↓
spinner поверх основного YouTube player
    ↓
service worker → POST/GET → local backend
                              ├─ yt-dlp + FFmpeg
                              ├─ Beat This! small0
                              ├─ lightweight structure analysis
                              └─ choreography planner
    ↓
готовая JSON-карта
    ↓
полная загрузка одного WebM-ассета
    ↓
один video-слой синхронизируется с currentTime YouTube
```

- До готовности карты отображается только белый spinner.
- При ошибке spinner заменяется красным `!`.
- Коты появляются только после получения карты и полной загрузки WebM в память.
- Между движениями выполняется резкий переход без второго видеослоя.
- Пауза, продолжение и перемотка следуют за основным YouTube video.
- Повторный анализ того же ролика использует локальный JSON-кеш.

## Установка

Сначала соберите и запустите backend по инструкции в [backend/README.md](backend/README.md).

Проверка доступности:

```bash
curl http://127.0.0.1:8765/health
```

Затем:

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `extension`.
5. Откройте URL вида `https://www.youtube.com/watch?v=...`.
6. Нажмите иконку Dancing Cats.

Видеоассет не входит в публичный репозиторий. Перед запуском поместите собственный файл по инструкции [ASSETS.md](ASSETS.md).

Badge показывает:

- `…` — backend анализирует трек или загружается WebM;
- `ON` — карта и ассет готовы;
- `!` — анализ или загрузка завершились ошибкой.

## Управление

- Перетащите всю группу котов левой кнопкой мыши.
- Используйте оранжевый маркер для изменения размера.
- Расширение не разделяет трёх котов на независимые объекты.
- Положение и размер сохраняются в `chrome.storage.local`.

## Хореография

[motion-map.json](extension/assets/cats/three-cats/motion-map.json) делит исходный WebM на короткие движения по четыре удара. Для каждого движения указываются:

- ожидаемая энергия, интенсивность и плавность;
- подходящий диапазон BPM;
- предпочтительные музыкальные секции;
- входная и выходная поза;
- допустимость резкого входа;
- возможность повтора и максимальное число повторов подряд;
- рекомендуемые последующие движения;

Backend выбирает движения по BPM, энергии и приближённой структуре `intro/verse/chorus/bridge/...`. Повторяющиеся части дополнительно получают стабильный `patternId`, а каждый такт — значения динамики, плотности атак и спектральных изменений. Loopable-движения разрешено повторять ограниченное число раз, поэтому энергичный фрагмент может дольше сохранять подходящий характер.

## Производительность backend

- Тяжёлые All-In-One и Demucs удалены из runtime.
- Небольшая модель `Beat This! small0` определяет только beats и downbeats непосредственно по исходному миксу.
- Структура, повторяемость, энергия и динамика вычисляются через `librosa` и NumPy без source separation.
- Backend загружает модель при старте и переиспользует её между заданиями.
- Загрузка модели и скачивание аудио нового задания могут выполняться параллельно.
- Для каждого job логируются времена скачивания/FFmpeg, rhythm inference, структурного анализа и построения карты.
- Новые музыкальные задания обрабатываются последовательно, чтобы ML-задачи не конкурировали за CPU и RAM.

```bash
PYTHONPATH=backend/src python3 -m unittest discover -s backend/tests -v

node --check extension/background.js
node --check extension/content.js
```

## Приватность и права

Расширение передаёт URL открытого ролика только локальному сервису на `127.0.0.1`. Backend временно скачивает аудиодорожку в рабочий каталог, удаляет её после задания и сохраняет только JSON-карту. Внешняя аналитика приложения отсутствует.

Перед публичным распространением обработанного WebM необходимо подтвердить права на исходный видеоматериал.
