# Dancing Cats for YouTube

Chromium-расширение накладывает прозрачных танцующих котов поверх обычных видео YouTube и Shorts и в real time подстраивает непрерывные движения под ритм вкладки.

Основной режим использует локальный backend с All-In-One: он заранее находит beats, downbeats и секции всей композиции, а затем строит хореографию с изменением движений, зеркалированием и масштабными импульсами. Real-time анализ вкладки остаётся fallback на время расчёта или при недоступном backend.

## Текущая архитектура

```text
tabCapture → offscreen AudioContext → beat detector
                                      ↓
asset catalog → motion map → time warping → overlay
```

- Аудио анализируется локально и не записывается.
- Beat detector оценивает BPM, фазу, confidence и энергию.
- Motion map разбивает WebM на законченные непрерывные движения.
- Временные якоря сопоставляют визуальные акценты ударам музыки.
- Между якорями кадры идут последовательно с плавно скорректированной скоростью.
- На границе движения планировщик выбирает отличный от текущего segment по энергии музыки, учитывая совместимость позы и рекомендуемые переходы.
- В конце полной фразы используется короткий crossfade.
- При паузе коты останавливаются; после перемотки анализ и план движения запускаются заново.

## Установка

Сначала запустите локальный анализатор по инструкции в [backend/README.md](backend/README.md). Он слушает `127.0.0.1:8765`; первый анализ может занять больше времени из-за загрузки ML-весов.

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `extension` этого репозитория.
5. Откройте видео на `https://www.youtube.com` и нажмите иконку Dancing Cats.

Видеоассет не входит в публичный репозиторий. Перед загрузкой расширения поместите собственный `video.webm` согласно [ASSETS.md](ASSETS.md).

Badge сначала показывает `…`, затем `AI…` во время анализа. `MAP` означает, что готовая карта загружена; `RT` — backend недоступен и используется real-time fallback. Повторный клик останавливает аудиозахват и удаляет оверлей.

Пока backend анализирует новый трек, работает локальный real-time detector. После появления готовой карты расширение автоматически переключается на хореографию, привязанную к `currentTime` YouTube. Повторный запуск того же видео использует JSON-кеш.

## Управление мышкой

- Перетащите котов левой кнопкой мыши.
- Используйте оранжевый маркер в правом нижнем углу для масштабирования.
- Положение и размер сохраняются локально.

Других редактируемых настроек в интерфейсе нет.

## Ассеты и карты движений

Каталог находится в [extension/assets/catalog.json](extension/assets/catalog.json). Каждый персонаж имеет отдельную папку с WebM и motion map:

```text
extension/assets/cats/three-cats/
├── video.webm
└── motion-map.json
```

Формат и добавление новых наборов описаны в [extension/assets/README.md](extension/assets/README.md).

Текущий ролик:

- VP9 с alpha channel;
- 608×690, 30 fps;
- 11,8 секунды;
- три последовательных движения по 8 ударов;
- 24 удара в полной фразе;
- естественный темп около 122 BPM.

Воспроизведение ассета из исходного файла:

```bash
tools/assets/process-reference-cats.sh input.mp4 extension/assets/cats/three-cats/video.webm
```

## Проверка

```bash
python3 tools/validate_extension.py
bash -n tools/assets/process-cats.sh tools/assets/process-reference-cats.sh
```

Валидатор проверяет Manifest, разрешения, каталог, пути, карты движений, непрерывность сегментов, временные якоря, переходы и метаданные WebM.

Ручной smoke-тест должен охватывать:

- обычное видео и Shorts;
- сохранение слышимого звука после `tabCapture`;
- начальный режим накопления и последующую синхронизацию;
- ритмичную музыку 90–150 BPM;
- pause/resume и seek;
- переход к следующему Shorts;
- drag/resize;
- полноэкранный режим;
- повторное выключение расширения.

## Приватность

PCM используется только в памяти offscreen document. Аудио, URL ролика и результаты анализа не передаются на сервер и не сохраняются.

Перед публичным распространением обработанных видеоассетов необходимо подтвердить права на их использование.
