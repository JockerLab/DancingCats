# Dancing Cats for YouTube

Chromium-расширение накладывает полное видео с танцующими котами поверх обычных видео YouTube и Shorts.

Текущая версия — простой визуальный прототип:

- полный 11,8-секундный референс без зелёного фона;
- оригинальная последовательность кадров без разворота и перемоток;
- циклическое воспроизведение с исходной скоростью;
- пауза и продолжение вместе с YouTube-видео;
- ручное перетаскивание мышкой;
- масштабирование угловым маркером;
- сохранение последнего положения и размера;
- без захвата аудио, BPM-анализа и панели настроек.

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `extension` этого репозитория.
5. Откройте видео на `https://www.youtube.com` и нажмите иконку Dancing Cats.

Badge `ON` означает, что оверлей включён. Повторный клик по иконке удаляет его.

## Управление мышкой

- Наведите курсор на область котов: появится пунктирная рамка.
- Зажмите левую кнопку внутри рамки и перетащите котов.
- Потяните оранжевый маркер в правом нижнем углу, чтобы изменить размер.

Положение и размер сохраняются локально в `chrome.storage.local`.

## Видеоассет

Расширение использует [three-cats.webm](extension/assets/cats/three-cats.webm):

- VP9 с alpha channel;
- 608×690;
- 30 fps, 354 кадра;
- 11,8 секунды;
- без аудиодорожки;
- около 2,6 МБ.

Ассет воспроизводится из оригинала командой:

```bash
tools/assets/process-reference-cats.sh input.mp4 extension/assets/cats/three-cats.webm
```

Исходный файл не скачивается скриптом автоматически. Перед публичным распространением необходимо подтвердить право включать обработанный ролик в расширение.

## Проверка

```bash
python3 tools/validate_extension.py
bash -n tools/assets/process-cats.sh tools/assets/process-reference-cats.sh
```

Ручной smoke-тест:

- включение и выключение по иконке;
- обычное видео и Shorts;
- полный цикл из 11,8 секунды;
- play/pause;
- перетаскивание и масштабирование;
- сохранение положения после перезагрузки;
- оконный и полноэкранный режим;
- переход к следующему Shorts.

## Приватность

Расширение не захватывает и не анализирует звук, не содержит аналитики и не отправляет данные на сервер.

История архитектурных решений находится в [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md).
